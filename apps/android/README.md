# SmartEat Printer Agent Android

This folder documents the Android target for the existing Vue UI.

The actual Android native project is generated by Capacitor in the root-level
`android/` folder. Capacitor uses the Vite build output from `frontend/dist`.

## Commands

From the repository root:

```powershell
npm.cmd run build:web
npm.cmd run android:sync
npm.cmd run android:open
```

## Important

Android cannot run Electron or Node desktop APIs. Any desktop-only code such as
`ipcRenderer`, `electron-store`, Express, Windows spooler printing, or Node TCP
printing must be replaced by Capacitor/native Android services before the app
can print directly from Android.
